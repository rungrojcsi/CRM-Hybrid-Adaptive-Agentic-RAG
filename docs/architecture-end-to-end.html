CRM · Hybrid Adaptive Agentic RAG · end-to-end

Two pipelines, one classifier, one grounded answer

An hourly ingest turns the Dynamics 365 model into account-centric markdown and indexes it; at ask time an intent classifier sends the question down the numeric path (generated DAX against the live Power BI model), the narrative path (hybrid vector search), or both, and unifies the parts into a single Thai answer.

  • /api/ask-hybrid — intent-routed entry point

Grounding contract

Where numbers come from

  • Aggregates are never written by the LLM — DAX runs against the certified Power BI model over XMLA
  • Narrative comes from one markdown doc per account, plus solution / salesperson / industry lenses
  • Provenance links each figure back to the accounts it came from
